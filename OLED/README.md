# OLED

使用 I2C 接口的 SSD1306 屏幕驱动。

适配 128x64、128x32、72x40 分辨率。

<br>

## 代码结构

### INKPTR_OLED.c

| Part | 名称 | 说明 |
| :-: | :-- | :-- |
| 1 | 库引用 | 引入宏定义参数和标准外设接口 |
| 2 | 显示参数 | OLED 型号参数表和初始化命令表 |
| 3 | 边界检查函数 | 检查页、列地址值是否超出当前型号范围 |
| 4 | 数据头封装 | 封装命令起始和数据起始的 I2C 时序 |
| 5 | 功能函数 | 显示设置、填充、绘图、滚屏函数 |
| 6 | 初始化函数 | 初始化 OLED 显示 |

【移植注意】
- **Part 1**：库名
- **Part 4**：I2C 时序函数名
- **Part 5**：I2C 时序函数名
- **Part 6**：初始化接口函数名、结构体类型名、成员名、枚举名

### INKPTR_OLED.h

| Part | 名称 | 说明 |
| :-: | :-- | :-- |
| 1 | 可调参数宏定义 | 屏幕分辨率 |
| 2 | 固定参数宏定义与枚举 | 屏幕 I2C 地址和各参数枚举 |
| 3 | 库引用与接口声明 | 引用变量类型定义，提供本代码模块的函数接口 |

【移植注意】
- **Part 1**：选择对应的屏幕分辨率
- **Part 3**：库名
