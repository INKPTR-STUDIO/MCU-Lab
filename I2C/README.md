# I2C

使用时钟线 SCL 和数据线 SDA 进行通信的协议，两线均应为开漏输出模式。

<br>

## 代码结构

### INKPTR_I2C.c

| Part | 名称 | 说明 |
| :-: | :-- | :-- |
| 1 | 库引用 | 引入宏定义参数和标准外设接口 |
| 2 | 延时函数 | SCL 电平变化后的延时，用于控制 I2C 的通信速度 |
| 3 | 引脚封装 | 引脚电平操作的封装，用于时序模块的调用 |
| 4 | 通信时序模块 | 实现软件 I2C 协议的核心时序 |
| 5 | 初始化函数 | 用于初始化软件 I2C 所需的引脚 |

【移植注意】
<br>**Part 1**：库名
<br>**Part 2**：通信速率延时
<br>**Part 3**：操作引脚的接口函数名
<br>**Part 5**：初始化接口函数名、定义名

### INKPTR_I2C.h

| Part | 名称 | 说明 |
| :-: | :-- | :-- |
| 1 | 可调参数宏定义 | 设置 GPIO 时钟、速度、端口、引脚 |
| 2 | 库引用与接口声明 | 引用变量类型定义，提供本代码模块的函数接口 |

【移植注意】
<br>**Part 1**：根据需求调整 I2C 要使用的引脚及其属性
<br>**Part 2**：库名
