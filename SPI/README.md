# SPI

使用片选线 CS、时钟线 SCK、数据线 MOSI 和 MISO 进行通信的协议，其中 CS、SCK、MOSI 为推挽输出模式，MISO 为浮空输入模式。

适配 4 中工作模式。

<br>

## 代码结构

### INKPTR_SPI.c

| Part | 名称 | 说明 |
| :-: | :-- | :-- |
| 1 | 库引用 | 引入宏定义参数和标准外设接口 |
| 2 | 延时函数 | CS、SCK 电平变化后的延时，用于控制 SPI 的通信速度 |
| 3 | 引脚封装 | 引脚电平操作与读取的封装，用于时序模块的调用 |
| 4 | 各模式交换字节时序模块 | 实现四种 SPI 模式的字节交换时序 |
| 5 | 通信时序模块 | 实现 SPI 起始、停止及字节交换的顶层调用 |
| 6 | 初始化函数 | 用于初始化软件 SPI 所需的引脚 |

【移植注意】
- **Part 1**：库名
- **Part 2**：通信速率延时
- **Part 3**：操作引脚的接口函数名
- **Part 5**：操作引脚的接口函数名
- **Part 6**：初始化接口函数名、结构体类型名、成员名、枚举名

### INKPTR_SPI.h

| Part | 名称 | 说明 |
| :-: | :-- | :-- |
| 1 | 可调参数宏定义 | 设置 GPIO 时钟、速度、端口、引脚及 SPI 工作模式 |
| 2 | 库引用与接口声明 | 引用变量类型定义，提供本代码模块的函数接口 |

【移植注意】
- **Part 1**：根据需求调整 SPI 要使用的引脚及其属性、设置 SPI 工作模式（0 ~ 3）
- **Part 2**：库名
